# Result index

One directory per TokenSpeed commit, named `arch_compare_<short-sha>/`, each
comparing MI355X (`gfx950`) and MI455X (`gfx1250`) on that commit.

Every entry is generated by
[`../scripts/generate_arch_comparison.py`](../scripts/generate_arch_comparison.py)
from four files: a `performance` result and a `hotspots` result from each
architecture. Nothing in an entry is written by hand, so it can be rebuilt from
its inputs. [`../docs/arch-comparison.md`](../docs/arch-comparison.md) is the
procedure.

An entry holds:

| Path | Contents |
|---|---|
| `README.md` | provenance, end-to-end performance, functional-group breakdown, heaviest kernels per stage |
| `kernel-tables/<arch>/<batch>-<stage>.csv` | every kernel symbol for that stage, not just the heaviest |

A new commit gets a new directory. Never overwrite an entry with numbers from a
different commit, and never mix architectures or stages measured at different
commits inside one entry.

Earlier single-architecture entries and the physical eight-GPU serving entry
were removed: they were measured at TokenSpeed `0b1061eb` against a harness
that no longer runs, and this package now covers both architectures per commit.
They remain in git history if the old numbers are ever needed.
